# 🏢 CleanTrac Admin Access - SIMPLIFIED

## 🎯 **One Simple Rule**

**Each domain automatically shows its own data - no switching needed!**

---

## 🔗 **Admin URLs (Production)**

### **Main System Admin**
- **URL**: `https://api.cleantrac.com/admin/`
- **Shows**: Public schema (tenant management, system config)
- **Use**: Add tenants, manage domains, system administration
- **Visual**: 🔧 RED badge "PUBLIC SCHEMA"

### **Cape Station Tenant Admin**
- **URL**: `https://api.capestation.com/admin/`
- **Shows**: Cape Station data (users, tasks, departments)
- **Use**: Daily operations, user management, task creation
- **Visual**: 🏢 GREEN badge "CAPE STATION"

---

## ✅ **How It Works**

1. **Go to the domain you want to manage**
2. **Add `/admin/` to the URL**
3. **Login with your admin credentials**
4. **See that domain's data automatically**

**No switching, no confusion, no complex menus!**
